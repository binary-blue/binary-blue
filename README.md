## 🎭 Two Sides of the Same Repo

I run two GitHub personalities — professional, organized, career-focused **me**, and *"fuck it, let's build it"* **me**. Same person, different modes.

| 🧑‍💼 Professional Mode | 🌀 Chaos Mode |
|---|---|
| Clean commits, clear messages | Commit message: `fix` (again) |
| Documented, tested, reviewed | Works on my machine — `¯\_(ツ)_/¯` |
| Follows the roadmap | **Is** the roadmap, discovered live |
| Ships on schedule | Ships when it ships |
| Reads the docs first | Reads the stack trace first |
